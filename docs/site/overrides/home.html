Features

Saved filters

Saved once, offered on every table with the same columns. 28 ship for EvtxECmd, RECmd and MFTECmd output, and [ ] step through them.

See it in action

Timeframe filter

Kept apart from the other filters: clearing them or stepping through saved ones leaves it on. One range for the whole case, or one per table.

See it in action

Histogram

When the rows in view happened, colored by tag, by one value or by group. Drag across it to set the timeframe.

See it in action

Derived columns

Sortable times from epochs and FILETIMEs, fields out of JSON and XML, regex captures, decodes, and lookups into another table. The original column is never changed.

See it in action

SQL pane

Read-only SQL over every table in the case, with its tags, notes and derived columns. Tag the rows a query returns, export them, or save them as a table.

See it in action

First and last plugin

Thousands of events down to the first and last of each group, per host or per user, as a new table you can tag and export.

See it in action

Pivot tables plugin

A cross-tab of any table, merged ones included: drag fields into rows, columns and values, and filter by tag.

See it in action
